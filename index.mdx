WeKnora is an open-source, LLM-powered knowledge platform from Tencent that brings your team's documents together so they can be searched, reasoned over, and kept up to date. Use RAG for instant Q&A with citations, the agent for multi-step tasks with tools and sandboxed code, and the wiki to automatically organize knowledge from your documents.

## Get Started in 3 Steps

<Steps>
  <Step title="Clone and configure">
    Clone the repository, copy `.env.example` to `.env`, and set your LLM API key and a `JWT_SECRET`.

    ```bash
    git clone https://github.com/Tencent/WeKnora.git
    cd WeKnora
    cp .env.example .env
    # Edit .env: set OPENAI_API_KEY (or another LLM), JWT_SECRET, and AES_KEY
    ```
  </Step>
  <Step title="Start the services">
    Pull images and start the core services. The web UI will be available at `http://localhost`.

    ```bash
    docker compose pull
    docker compose up -d
    ```
  </Step>
  <Step title="Create a knowledge base and ask a question">
    Open `http://localhost`, complete onboarding, upload a document to a knowledge base, and ask your first question in the chat.
  </Step>
</Steps>

<Note>
  For local LLM support via Ollama, run `ollama serve` before starting WeKnora and set `OLLAMA_BASE_URL` in your `.env`. See [Configuration](/configuration) for all environment variables.
</Note>
